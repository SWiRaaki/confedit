Hilfe & Anleitung

📝 Erste Schritte

  1. Wählen Sie im Datei-Bereich eine Konfigurationsdatei aus dem Dateibaum aus
  2. Klicken Sie auf Bearbeiten, um die Datei zu ändern
  3. Speichern Sie Ihre Änderungen mit dem Speichern-Button
  4. Überprüfen Sie den Versionsverlauf unter Versionen

📁 Dateiverwaltung

  • Datei anzeigen: Klicken Sie auf eine Datei im Dateibaum
  • Datei bearbeiten: Klicken Sie auf "Bearbeiten" oder nutzen Sie den Menüpunkt
  • Neue Datei: Nutzen Sie den "Neue Datei erstellen" Button
  • Datei hochladen: Nutzen Sie den "Datei hochladen" Button

❓ Häufige Fragen (FAQ)

Wie kann ich eine neue Datei hinzufügen?

Nutzen Sie den "Neue Datei erstellen" Button im Aktionsbereich der Hauptseite.

Wie kann ich Rechte ändern?

Gehen Sie zur Benutzer-Seite und bearbeiten Sie die Rechte in der Tabelle.

Wie funktioniert die Versionsverwaltung?

Jede Änderung wird automatisch als neue Version gespeichert. Sie können ältere Versionen wiederherstellen oder vergleichen.

Was passiert bei Syntaxfehlern?

Das System validiert Ihre Eingaben und zeigt Fehler an, bevor die Datei gespeichert wird.
